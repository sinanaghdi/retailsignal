# Semantic model

- Mode: Import
- Local source parameter: `ProjectRoot`, which must point at the repository root.
- Main fact: `FactSalesLine`, one row per original ingested source row.
- Date grain: one row per calendar day generated by the preflight utility.
- Relationship direction: dimension-to-fact, one-to-many defaults in TMDL.
- Customer RFM and cohort retention tables are precomputed full-window marts and remain separate from fact filters.
- DAX measures follow the definitions in `powerbi/measures.md`.

Power BI Desktop validation is still required before treating this model or report as released.
