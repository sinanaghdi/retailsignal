# LinkedIn Project Description (Ready to Publish After Validation)

Built **RetailSignal**, a reproducible e-commerce analytics case study using the UCI Online Retail II dataset. The project brings together Python/pandas for data-quality assessment and transformations, PostgreSQL for analytical modeling and customer/cohort queries, and a planned Power BI executive dashboard.

The analysis is designed to separate signed recorded transaction value from eligible positive line sales, document cancellation and negative-line patterns, and evaluate product/country contribution and identified-customer repeat purchasing without overstating what the source can prove. The repository includes reproducible setup instructions, metric definitions, SQL, automated synthetic unit tests, data-quality reconciliation checks, and a transparent limitations section.

**Tools:** Python, pandas, NumPy, PostgreSQL, SQL, SQLAlchemy, pytest, Jupyter, Power BI.
