# Data Dictionary

## Source columns

| Canonical field | Expected source meaning | Normalized type | Notes |
|---|---|---|---|
| `InvoiceNo` / `invoice_no` | Invoice identifier | String | Prefix `C` marks cancellation in UCI documentation; keep leading zeros and case-normalize only for the derived flag |
| `StockCode` / `stock_code` | Product/item code | String | Do not infer categories from the code |
| `Description` / `description` | Product description | Nullable string | Descriptions may be absent or inconsistent for the same code |
| `Quantity` / `quantity` | Units recorded for the line | Numeric | Negative values retained and flagged |
| `InvoiceDate` / `invoice_date` | Source transaction timestamp | Datetime, nullable if invalid | Time-zone semantics are not specified; do not invent a zone |
| `UnitPrice` / `unit_price` | Price per unit in GBP | Numeric | Zero/negative values retained and flagged |
| `CustomerID` / `customer_id` | Customer identifier | Nullable string | Missing IDs excluded from customer-level measures; never impute identity |
| `Country` / `country` | Country label | Nullable string | Source-defined value; no category/demographic inference |
| `source_sheet` | Worksheet of origin | String | Provenance for workbook ingestion |
| `source_row_id` | Generated sequential row identifier | Integer | Deterministic within a given workbook sheet order, not a source business key |

## Derived line fields

| Field | Meaning |
|---|---|
| `line_value` | `quantity * unit_price`; signed and calculated once |
| `is_cancellation_invoice` | `invoice_no` starts with `C` after trimming and uppercasing |
| `is_negative_quantity` | Quantity less than zero |
| `is_zero_quantity` | Quantity equals zero |
| `is_nonpositive_unit_price` | Unit price is zero or negative |
| `is_negative_line_value` | Signed line value less than zero |
| `is_positive_sales_line` | Quantity > 0, unit price > 0, line value valid, and not cancellation-prefixed |
| `is_credit_or_return_like` | Cancellation prefix OR negative signed line value; a diagnostic flag, not a physical-return assertion |
| `is_exact_duplicate_extra_row` | Row matches an earlier row across canonical source fields; kept for sensitivity analysis |

## Data mart fields

Marts are generated by `src.clean` and `src.metrics`; exact columns are documented in the CSV headers after execution. Key fields include `month`, `net_recorded_sales_gbp`, `gross_positive_line_sales_gbp`, `negative_line_value_gbp`, `sales_invoices`, `customer_id`, `recency_days`, `frequency_invoices`, `monetary_recorded_gbp`, `cohort_month`, `activity_month`, `cohort_index`, `retention_rate`, `sales_contribution_pct`, and `cumulative_contribution_pct`.

All monetary field names carry `_gbp` where applicable. No dataset field measures profit, cost of goods sold, acquisition spend, or marketing attribution.
